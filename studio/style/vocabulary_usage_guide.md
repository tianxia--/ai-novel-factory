# 词汇使用策略指南

> Vocabulary Usage Strategy Guide

## 🎯 核心原则

### 1. 词汇使用金字塔

```
        稀有/成语 (5%)
       ─────────────
     高级词汇 (15%)
      ──────────
    进阶词汇 (30%)
   ────────────
  基础词汇 (50%)
  ───────────
```

**使用比例：**
- 基础词汇：50% - 保证可读性
- 进阶词汇：30% - 丰富表达
- 高级词汇：15% - 提升文采
- 稀有/成语：5% - 点睛之笔

## 📊 词汇等级定义

### 基础词汇 (Level 1)
- **特征**：日常常用，人人能懂
- **举例**：走路、说话、吃饭、睡觉、高兴、难过
- **使用场景**：90%以上的句子
- **频率**：每10个词中占5个

### 进阶词汇 (Level 2)
- **特征**：略高级，但仍常见于现代文
- **举例**：行走、交谈、用膳、就寝、喜悦、忧伤
- **使用场景**：需要更有文采时
- **频率**：每10个词中占3个

### 高级词汇 (Level 3)
- **特征**：文雅，有古风，适合古装剧/小说
- **举例**：踱步、寒暄、品茗、安寝、欣喜、惆怅
- **使用场景**：关键描写段落、人物对话
- **频率**：每10个词中占1.5个

### 稀有/成语 (Level 4)
- **特征**：古雅、成语、典故，不宜滥用
- **举例**：蹑足潜踪、促膝长谈、品味佳茗、安然入睡
- **使用场景**：偶尔使用，画龙点睛
- **频率**：每10个词中占0.5个

## ⚠️ 成语使用禁忌

### 核心原则：成语必须与文本关联

**什么是成语关联？**

成语必须与上下文有直接的、逻辑的、语义的联系，不能为了用成语而用成语。

### 关联性检查清单

使用成语前，请回答以下问题：

1. **这个成语是否与当前描述的内容直接相关？**
   ```
   ✅ 他看着漫天飞雪，想起"瑞雪兆丰年"的老话。
      （成语与描述的雪景直接关联）

   ❌ 天气很好，他心情不错，真是"喜上眉梢"。
      （成语与天气描述没有直接关联，逻辑跳跃）
   ```

2. **这个成语是否与人物身份/性格匹配？**
   ```
   ✅ 老夫子推了推眼镜，摇头晃脑地说："学而不思则罔啊。"
      （成语与老夫子身份匹配）

   ❌ 小农民看着田地，心中暗想："这真是沧海桑田啊。"
      （成语与小农民身份不匹配）
   ```

3. **这个成语是否与场景氛围一致？**
   ```
   ✅ 战场上刀光剑影，杀声震天，正是"兵临城下"之势。
      （成语与战争场景氛围一致）

   ❌ 温馨的家庭聚餐，大家笑着说"真是惊涛骇浪的一天"。
      （成语与温馨氛围不符）
   ```

4. **去掉这个成语，句意是否完整？**
   ```
   ✅ 他努力工作，终于功成名就。 （去掉"功成名就"，句意仍完整）
   ❌ 他真是"才高八斗"。 （去掉成语，句意不完整，说明是为了用而用）
   ```

### 禁用场景

1. **对话中过度使用**
   ```
   ❌ 他微笑着说："令弟真是才高八斗，学富五车啊！"
      （成语与对话内容无直接关联，显得做作）

   ✅ 他笑着说："你弟弟真有才华，文章写得不错。"
      （直接描述，自然流畅）
   ```

2. **心理描写中堆砌**
   ```
   ❌ 他心中七上八下，忐忑不安，如履薄冰，如坐针毡。
      （4个成语堆砌，没有具体内容）

   ✅ 他心里很不安，不知道老师会不会批评他。
      （具体描写不安的原因和表现）
   ```

3. **动作描写中强行植入**
   ```
   ❌ 他龙行虎步，大步流星，健步如飞地走了过来。
      （成语与动作描述无直接关联，显得生硬）

   ✅ 他快步走了过来，每一步都很稳，气势不凡。
      （具体描写步伐和气势）
   ```

4. **无关联场景使用**
   ```
   ❌ 看着满桌的饭菜，他真是"垂涎三尺"。
      （成语与看饭菜的情景无直接关联，"垂涎"通常用于想吃的心理）

   ✅ 看着满桌的饭菜，他觉得很香，肚子都饿了。
      （直接描写感受，自然）
   ```

### 推荐使用场景

成语使用必须满足：**有内容、有原因、有逻辑**

1. **总结性场景 - 有内容基础**
   ```
   他努力工作了三年，每天早起晚睡，从不懈怠。就这样坚持下来，
   终于功成名就。
   ──────────────────────── ↑
      有具体的内容描写在前，成语是总结
   ```

2. **对比性场景 - 有对比目的**
   ```
   虽然敌人兵临城下，但他临危不乱，指挥若定。
   ────────────────────── ↑ ↑
      危机情境 对比 成语展示人物性格
   ```

3. **强调性场景 - 有强调重点**
   ```
   这真是千载难逢的机会，他一定要抓住。
   ─────────────────── ↑
      强调机会的难得，成语起到强调作用
   ```

### 成语使用的"三要三不要"

**三要：**
1. ✅ 要有前文铺垫
2. ✅ 要有逻辑关联
3. ✅ 要符合场景氛围

**三不要：**
1. ❌ 不要孤零零地使用
2. ❌ 不要堆砌叠加
3. ❌ 不要强行植入

## 🎨 场景化使用策略

### 场景1：宫廷/贵族环境
- **推荐词汇**：宸阙、帝阙、龙椅、丹墀、圣谕、诏书
- **使用原则**：适度使用宫廷词汇，保持庄重
- **避免**：过度堆砌，导致晦涩

### 场景2：军事战场
- **推荐词汇**：鏖战、冲锋、突袭、溃败、兵临城下
- **使用原则**：动词为主，名词为辅
- **避免**：过多成语，削弱紧张感

### 场景3：日常生活
- **推荐词汇**：晨曦、暮色、炊烟、阡陌、邻里
- **使用原则**：贴近生活，自然流畅
- **避免**：过于古雅的词汇

### 场景4：情感描写
- **推荐词汇**：欣慰、愧疚、惆怅、忐忑、欢喜
- **使用原则**：情感词汇要具体，不要堆砌
- **避免**：连续使用多个情感词汇

## 📝 写作技巧

### 技巧1：词汇混搭
```
基础词汇 + 高级词汇 = 自然的文采
```
**示例：**
```
✅ 他慢慢地走到窗前，看着外面飘落的雪花。
   (慢慢 - 基础，踱步 - 高级，但这里用慢慢更自然)
```

### 技巧2：成语点睛
```
整段平铺直叙 + 一个成语 = 画龙点睛
```
**示例：**
```
他努力工作，每天早起晚睡，从不懈怠。就这样坚持了三年，终于功成名就。
                   (成语放在结尾，起到总结和升华作用)
```

### 技巧3：词汇递进
```
基础表达 → 进阶表达 → 高级表达 → 稀有表达
```
**示例：**
```
他很高兴 → 他很欣慰 → 他心中欣喜 → 他喜上眉梢
```

## 🔍 自检清单

写作完成后，检查以下内容：

### 词汇密度检查
- [ ] 每段是否有过多的成语？（建议≤1个）
- [ ] 是否有连续的高级词汇？
- [ ] 基础词汇占比是否≥50%？

### 场景匹配检查
- [ ] 词汇是否符合当前场景？
- [ ] 是否有违和感的词汇？
- [ ] 人物说话的词汇是否匹配身份？

### 阅读流畅度检查
- [ ] 读一遍是否顺畅？
- [ ] 是否有需要查词典的词？（建议≤5个/章）
- [ ] 是否有重复使用的高级词汇？

## 💡 最佳实践

1. **先写后改**：先用基础词汇写出内容，再适当替换为高级词汇
2. **少即是多**：成语和高级词汇少用，效果更好
3. **角色匹配**：不同角色使用不同等级的词汇
4. **场景匹配**：不同场景使用不同风格的词汇
5. **整体平衡**：整章的词汇使用要保持平衡
