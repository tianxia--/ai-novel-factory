# AI 小说写作风格指南

> 本指南定义了 AI 写作时应遵循的风格、词汇使用、文言文穿插等规则

**重要：AI 在每次写作前，请先阅读本指南，并严格按照指南执行。**

---

## 📖 一、写作风格总原则

### 1.1 可读性优先
- 以现代文为主，保证读者能流畅阅读
- 文言文、高级词汇、成语只是点缀
- 不要让读者频繁查字典

### 1.2 层次丰富
- 基础词汇：50% - 保证可读性
- 进阶词汇：30% - 丰富表达
- 高级词汇：15% - 提升文采
- 稀有/成语：5% - 点睛之笔

### 1.3 自然流畅
- 不要堆砌词汇
- 不要为了展示文采而强行使用
- 像人说的话，不是词的堆砌

## 🎯 二、成语使用策略

### 2.1 成语使用的三个关联维度

**维度1：角色身份关联**
- 文人/官员：可以使用文雅成语（学富五车、才高八斗）
- 武将/粗人：使用少量简单成语（勇冠三军、力大无穷）
- 平民/百姓：几乎不用成语，用基础词汇

**维度2：角色性格关联**
- 谦虚谨慎：使用低调成语（谦受益、满招损）
- 自信张扬：使用张扬成语（气吞山河、不可一世）
- 憨厚老实：使用朴实成语（脚踏实地、勤勤恳恳）

**维度3：语境氛围关联**
- 正式场合（朝堂）：可以用庄重的成语
- 随意场合（日常）：少用成语，自然对话
- 紧张场合（战场）：用简洁有力的成语（临危不乱、力挽狂澜）

### 2.2 成语使用原则

**三要：**
1. ✅ 要有前文铺垫
2. ✅ 要有逻辑关联
3. ✅ 要符合场景氛围

**三不要：**
1. ❌ 不要孤零零地使用
2. ❌ 不要堆砌叠加
3. ❌ 不要强行植入

### 2.3 成语使用密度

| 场合 | 成语密度 | 每段 | 每章 |
|------|---------|------|------|
| 正式奏章 | 高 | 2-3个 | 10-15个 |
| 正式对话 | 中 | 1-2个 | 5-8个 |
| 随意对话 | 低 | 0-1个 | 2-4个 |
| 战场指挥 | 低 | 1个 | 3-5个 |
| 私下交谈 | 低 | 0-1个 | 2-3个 |
| 心理描写 | 低 | 0-1个 | 2-3个 |

### 2.4 成语使用示例

**✅ 正确示例：**
```
他每天清晨六点就起床，简单洗漱后就去图书馆。
中午匆匆吃个馒头，继续埋头苦读。晚上图书馆闭馆了，
他才拖着疲惫的身子回去。虽然很累，但想到自己的目标，
他又咬牙坚持。就这样，三个月如一日，从未间断。
                    ───────────── ↑
            "如一日"：总结三个月的努力
```
- 有具体细节
- 成语起到总结作用
- 与上下文有明确关联

**❌ 错误示例：**
```
他废寝忘食，孜孜不倦，夜以继日，日以继夜，手不释卷，
悬梁刺股，凿壁偷光，囊萤映雪，焚膏继晷，兀兀穷年，
持之以恒，坚持不懈，锲而不舍，百折不挠，坚韧不拔...
```
- 15个成语连续堆砌
- 没有具体内容
- 缺乏真实感

## 📖 三、文言文穿插策略

### 3.1 文言文穿插的三个层次

**第一层：词汇层面** - 用文言词汇替换现代词汇
```
现代：他说 "我不同意你的观点"
文言穿插：他说 "吾不以为然"
```

**第二层：句式层面** - 使用文言句式
```
现代：既然来了，就坐下来吧
文言穿插：既至，且坐
```

**第三层：段落层面** - 整段使用文言文
```
用于正式奏章、古书信、史书叙述
```

### 3.2 文言文使用比例

| 文本类型 | 现代文 | 文言 | 适用场景 |
|---------|-------|------|---------|
| 普通叙述 | 80% | 20% | 日常叙述 |
| 对话（非正式）| 95% | 5% | 朋友聊天 |
| 对话（正式）| 60% | 40% | 官员交流 |
| 奏章文书 | 20% | 80% | 正式文书 |
| 古书信 | 30% | 70% | 文人书信 |
| 史书叙述 | 40% | 60% | 史书记载 |

### 3.3 常用文言词汇

**代词：**
- 吾、余、朕、孤、末将、微臣 = 我
- 汝、尔、卿、公 = 你

**动词：**
- 诣 = 去、到
- 遣 = 派遣
- 诏 = 下诏书
- 奏 = 上奏章
- 闻 = 听说
- 视 = 看、视察

**副词：**
- 然 = 但是
- 遂 = 于是、就
- 乃 = 于是
- 立 = 马上
- 未 = 没有
- 已 = 已经

### 3.4 文言文穿插示例

**示例1：朝堂对话（30%文言）**
```
李大人上前一步，拱手行礼："陛下，微臣听闻南方水患严重，
百姓流离失所，特来请旨赈济。"
```
- 文言词汇：微臣、请旨

**示例2：武将书信（80%文言）**
```
末将张XX谨呈：

边关告急！蛮族大军压境，兵临城下。末将率部拼死抵挡，
然敌众我寡，形势危急。今已死守七日，城中粮草将尽，
援军未至。若再不派兵，边关危矣！
```
- 文言词汇：末将、谨呈、然、危矣

**示例3：史书叙述（60%文言）**
```
XX年，帝崩，太子XX即位，改元XX。
时南方大旱，三时不雨，禾稼皆枯。百姓流离失所，
饿殍遍野。帝闻之，大惊，立遣官赈济。
```
- 文言词汇：崩、即位、改元、三时、皆、闻、立

## 🎭 四、角色差异化写作

### 4.1 按身份差异化

**文人/官员：**
- 词汇：文雅、含蓄
- 句式：委婉、有礼貌
- 文言：30-40%
- 成语：中等到高

**武将/粗人：**
- 词汇：直白、有力
- 句式：简洁、干脆
- 文言：5-10%
- 成语：低，用简单成语

**平民/百姓：**
- 词汇：日常、朴素
- 句式：自然、随意
- 文言：0-5%
- 成语：几乎不用

**太监：**
- 词汇：委婉、顺从
- 句式：圆滑、客套
- 文言：10-20%
- 成语：低，用委婉成语

### 4.2 按性格差异化

**谦虚谨慎：**
- 使用低调词汇和成语
- 表达委婉，不张扬

**自信张扬：**
- 使用张扬词汇和成语
- 表达直接，有气势

**憨厚老实：**
- 使用朴实词汇
- 表达真诚，不浮夸

**老练圆滑：**
- 使用含蓄词汇
- 表达话中有话

### 4.3 按场合差异化

**正式场合（朝堂、奏章）：**
- 文言：40-80%
- 成语：高
- 风格：庄重、正式

**随意场合（日常、私聊）：**
- 文言：5-20%
- 成语：低
- 风格：自然、流畅

**紧张场合（战场、危机）：**
- 文言：5-10%
- 成语：低，用有力成语
- 风格：简洁、紧张

## 📝 五、写作流程

### 5.1 写作前检查

**第一步：分析场景**
- [ ] 当前是什么场景？（战场、朝堂、日常等）
- [ ] 是正式还是随意场合？
- [ ] 需要什么氛围？

**第二步：分析角色**
- [ ] 角色是什么身份？（文人、武将、平民等）
- [ ] 角色什么性格？（谦虚、张扬、憨厚等）
- [ ] 角色会怎么说话？

**第三步：确定风格**
- [ ] 文言文比例多少？
- [ ] 成语密度多少？
- [ ] 词汇等级如何？

### 5.2 写作中执行

**第一阶段：用基础词汇写出内容**
- 先把事情说清楚
- 表达完整，逻辑通顺

**第二阶段：根据角色和场景调整词汇**
- 文人多用文雅词汇，武将用直白词汇
- 正式场合用文言词汇，随意用现代词汇

**第三阶段：在关键处使用成语**
- 只在总结、强调、对比时使用
- 确保成语与上下文有关联
- 每段最多1个，每章3-5个

**第四阶段：通读检查**
- [ ] 是否流畅自然？
- [ ] 成语是否有关联？
- [ ] 文言文比例是否合适？
- [ ] 风格是否统一？

### 5.3 写作后自检

**检查清单：**
- [ ] 成语是否符合角色身份？
- [ ] 成语是否符合性格特征？
- [ ] 成语是否符合场合氛围？
- [ ] 成语是否与前文有关联？
- [ ] 成语密度是否合理？
- [ ] 文言文比例是否合适？
- [ ] 文言词汇是否正确？
- [ ] 风格是否统一？
- [ ] 是否保持可读性？

## 🎯 六、写作模板

### 6.1 对话写作模板

**文人对话（正式）：**
```
XXX上前一步，拱手行礼："[内容]。"
  └─ 使用微臣、请旨等文言词
  └─ 适当使用成语
  └─ 表达委婉有礼
```

**武将对话（直白）：**
```
XXX大步上前，单膝跪地："[内容]！"
  └─ 使用末将、肝脑涂地等文言词
  └─ 成语简洁有力
  └─ 表达直接干脆
```

**平民对话（自然）：**
```
XXX说："[内容]。"
  └─ 全现代文
  └─ 几乎不用成语
  └─ 表达自然随意
```

### 6.2 叙述写作模板

**普通叙述（20%文言）：**
```
[现代文描述]，[穿插1-2个文言词汇]，[继续现代文]。
  └─ 日常叙述，保持流畅
  └─ 文言词汇点缀
```

**史书叙述（60%文言）：**
```
[时间]，[事件]。[文言描述]。[结果]。
  └─ 仿史书笔法
  └─ 文言句式为主
  └─ 简洁凝练
```

### 6.3 文书写作模板

**奏章文书（80%文言）：**
```
[自称]谨[动作]：

[文言陈述问题]。[文言分析原因]。
[文言建议方案]。[文言表达决心]。

[自称] 拜上
[时间]
  └─ 正式奏章格式
  └─ 文言文为主
  └─ 表达庄重正式
```

## 💡 七、快速参考

### 7.1 关键要点速查

| 要点 | 说明 |
|------|------|
| 成语使用 | 有关联、不堆砌、符合角色 |
| 文言穿插 | 20-40%、根据场景调整 |
| 可读性 | 现代、流畅、不晦涩 |
| 角色差异 | 身份、性格、场合 |
| 风格统一 | 全文保持一致 |

### 7.2 常用错误

❌ **错误1：** 成语堆砌，没有内容
✅ **正确：** 有具体内容，成语点缀

❌ **错误2：** 文言过度，晦涩难懂
✅ **正确：** 文言适度，保持可读

❌ **错误3：** 半文半白混杂
✅ **正确：** 风格统一，比例恰当

❌ **错误4：** 不顾角色身份
✅ **正确：** 角色差异，身份匹配
