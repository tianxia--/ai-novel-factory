状态：planned。依据 [PRD](prd.md)，用[N01 清单](acceptance.md)验收。

| 实施项 | 对应需求 | 交付与验证 |
| --- | --- | --- |
| N01-T01 窄 API 与身份 | N01-R01、N01-R02、N01-R05 | 公开描述、项目只读分页、受限主体/资源 ACL，独立客户端负向测试 |

| N01-T06 交付 | N01-R01、N01-R02、N01-R03、N01-R04、N01-R05、N01-R06、N01-R07、N01-R08 | 独立构建/启动、兼容矩阵、N01 证据和用户验收记录 |

T01/T02 不依赖平台开发即可推进；T03 定义领域事务后再做 T04/T05。修改现有函数前跑 GitNexus context/impact，按真实调用方覆盖回归。

保留原 CLI/worker/界面，新增能力接口不能开放旧 owner 管理权限。回退停用新增接口/插件，保留候选、operation 与已有正式版本；不删除资料来恢复通过状态。
