# 小说适配器 n0.1 PRD：独立读写候选闭环

日期：2026-10-20。状态：planned。这是独立能力版本，不是平台版本。平台定位见[总 PRD](../../../README.md)，领域边界见[接入架构](../../../../architecture/novel-integration.md)。8 项需求均为 must。

## 目标与流程

获准调用者读取已有小说的概要与指定章节上下文，人物/外部客户端提交自己写出的正文候选，得到真实版本与操作状态。领域服务不要求调用者使用 IM、Pi 或 OpenCode；平台也不要求安装这个能力。

配置小说服务账号 → 查询获准项目 → 选章节及上下文版本 → 调用者创作正文 → 提交带基准版本的候选 → 查询 operation → 读取新候选版本。与 IM 组合时，在通用能力库安装插件、给人物授权，再复用上述流程。

章纲/设定创建、完整自动写作、审稿批准、正式章节提升和外部发布后置到独立后续版本。本版不能通过隐藏旧完整流水线来完成候选提交。

## 功能需求

| ID | 必须实现的行为 | 验收 |
| --- | --- | --- |
| N01-R01 | 服务提供版本化描述与独立 API/CLI 验证入口，声明工具/契约/限制，不启动 IM 也可运行 | N01-A01 |
| N01-R02 | 只列出/读取当前主体获准项目，分页稳定，拒绝任意路径和未授权资源，信息不泄漏 | N01-A02 |
| N01-R03 | chapter_context_get 为真实只读查询，返回明确资料版本/引用；缺前置资料返回缺项，不补写文件或调用模型 | N01-A03 |
| N01-R04 | 接收显式正文和 baseVersion，保存不可变候选；不自动审稿/提升/改 Canon；并发冲突不静默覆盖 | N01-A04 |
| N01-R05 | 调用身份可信，资源范围独立校验；同 invocation 重试复用 operation/候选，同键异参数冲突 | N01-A05 |
| N01-R06 | 获准查询/取消 operation；崩溃/未知提交效果可核对，取消竞争显示实际事实，重启不重做效果 | N01-A06 |
| N01-R07 | 薄 MCP/Skills 插件仅依赖公开 API，可用独立 MCP 客户端发现/调用/读结果；不引入两项目内部模块或数据连接 | N01-A07 |
| N01-R08 | 可在平台 v0.2 支持的契约下组合，停用/停止任一方不破坏另一方；旧小说入口相关回归不新增失败 | N01-A08 |

## 数据、状态与验收

factory.sqlite 及领域版本清单保存小说事实，IM 只保存外部引用。凭据经连接插件/网关保护，模型不获得 owner 管理 token 或服务目录。对未知 schema/契约显式拒绝。

提交/状态/成果 Schema 采用约定的能力契约版本；只读工具使用自己的输出 Schema。operation 受理并不表示正文已经保存；成功必须返回可重读的候选版本，未知状态进入待核对。

8 项通过、相关小说回归按同条件基线分类并无新增失败，且无本版阻断缺陷后才能工程验收。真实组合验收需要已通过的平台契约，不强制平台和小说同时发布；没有条件时相关用例记 blocked。
