# 独立能力项目的 PRD 与迭代

平台接收符合公开契约的能力，业务类型开放。能力由提供方单独实现、部署、版本化和验收；安装/挂载不是平台为其领域正确性背书。

## 接入流程

确定用户目标与输入/成果 → 在能力项目建立版本 PRD → 明确工具、知识、账号、资源范围与副作用 → 制定公开契约与实施计划 → 独立客户端验收 → 通用 IM 安装/人物授权/工作绑定 → 组合验收 → 发布兼容版本。

每个能力版本至少有 prd.md、implementation-plan.md、acceptance.md 和具体构建验收记录，沿用[交付流程](../delivery-process.md)。服务和插件可分开发布，记录实际兼容关系。尚未形成完整 PRD 的路线项不能直接进入实现或宣称通过。
