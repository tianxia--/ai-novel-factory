## 1. 环境与证据

隔离 IM 数据目录；两个人物、一个无权观察的第三人、两个模型配置、一个群；没有小说服务/源码依赖。真实模型和确定性替身分开标记；费用与用量写入报告。每项保存实际操作/断言和必要截图、版本/日志 ID，日志脱敏。

| 用例 | 需求 | 前置与步骤 | 通过标准与证据 |
| --- | --- | --- | --- |
| P01-A01 | P01-R01 | 无模型创建人物；修改名称/人格并保存；重启 | 可暂停保存，ID 不变，版本递增，旧版本更新被拒绝；数据库/API 证据 |
| P01-A02 | P01-R02 | 两人选不同模型；分别使用有效/无效配置并发消息 | 各自用指定配置；失败明确、凭据不回显；真实请求与计费记录可核对 |
| P01-A03 | P01-R03 | 人机 DM 双向重开，人物 A 联系 B，再用 C/所有者普通视角读和代发 | 每对一条 DM，作者正确，C 无正文/摘要，所有者不能冒充；含 API 负向证据 |
