## 宿主和范围

实施位置为内部参考工程。新增人物观察查询与界面，不把 IM 放进小说数据库。IM 使用自己的 `team.sqlite`、构建和进程；小说服务及小说插件未启动。

本批关联 P01-T01、P01-T05、P01-T06，主要对应 P01-R07，部分覆盖 P01-R09、P01-R10。当前复用宿主 Pi；没有完成 OpenCode 运行时接入。之前的 OpenCode PoC 和小说同库 collab 原型保留作历史输入，不是并行的生产聊天服务。

## 已实现

- 观察人物自己的私聊、同事会话、群、公开联系人信息、当前可见工作、记忆及已存在 Session。
- 聊天与工作 Session 分开查询；支持历史重试 Session 和实际记录的模型，缺失的历史模型不使用当前配置冒充。
- 消息稳定游标分页；按当前群成员历史边界过滤消息、预览、工作和 Session；无权内容返回 404。
- 观察查询不创建 Session、不调用模型、不标记已处理、不写记忆。观察上下文写请求在后端拒绝，界面无发送或审批入口。
- 人物切换隔离缓存，取消旧查询；迟到响应不能覆盖新人物；桌面/手机布局和中英文入口。

独立 IM 的 protocol/core/server 类型构建、前端生产构建、测试类型检查通过。最终完整 `npm run check` 门禁通过，215 个测试文件、1,940 项测试通过；定向共 21/21 通过。截图和命令证据在独立宿主 `docs/platform/verification-2026-10-20.md`，不代表整版产品验收。

真实临时后端加隔离 Chrome 检查：重复点击会话、人物快速切换及迟到响应、无写请求、无输入框、联系人位图头像正常；320/390/900/1440px 长姓名与长消息无水平溢出，无浏览器未捕获错误。另测 640x450 CSS 像素的缩放等效布局，不冒称已完成原生 200% 缩放验收。

浏览器数据是明确标记的隔离测试档案和所有者消息，没有付费模型调用；不能据此判定真实模型、多人物协作或外部能力验收通过。
