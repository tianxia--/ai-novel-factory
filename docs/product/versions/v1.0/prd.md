# v1.0 PRD：正式本地版本

日期：2026-10-20。状态：planned。依赖前三版已验收行为。需求共 8 项，均为 must；对应 [P10 验收](acceptance.md)。

## 1. 用户结果与范围

用户能持续使用通用 IM 和已安装能力，升级、备份、故障恢复与诊断可执行，版本承诺与真实产品一致。正式发布仍面向明确支持的平台/本地所有者，不自动扩大为云端多租户或跨设备同步。

发布前锁定支持矩阵：操作系统/架构、运行时、桌面/浏览器、Harness、插件和契约版本。未验证的平台明确不在本次支持范围，不用笼统“全平台”描述。

## 2. 主流程与页面

安装具体产物 → 完成初始配置 → 日常聊天和工作 → 设置查看版本/数据/诊断 → 创建一致性备份 → 升级 → 校验历史与待处理工作 → 必要时按兼容方案恢复 → 继续使用。

设置页包含版本、数据范围、备份/恢复和脱敏诊断。界面明确恢复会影响哪些数据、当前是否仍有外部 operation；不宣称回退 IM 能回滚第三方已经发生的动作。

## 4. 数据与恢复规则

备份 IM 时暂停其写入并一致性导出自身数据库及必需资源；每个能力服务按自己的机制备份。记录安装实例、资源版本和未决操作引用；不虚构跨服务全局事务。提供方暂不可用时记录待核对，恢复后重新查询，不能以聊天缓存覆盖业务状态。

升级前运行兼容预检，存在活跃外部写入时先收束或记录明确续跑/对账方案。不可兼容回退从已验证备份恢复，保留之后发生的外部动作清单，不静默删除资料或重发效果。

## 5. 非功能基线

参考数据集：20 个人物、50 个群、50,000 条消息和至少 100 条已完成/未决工作记录，固定测试数据和硬件/操作系统/构建写入验收报告。预热后 30 次本地会话最近页/切换读取的 p95 不超过 1 秒；排除模型生成与远程服务时间，但单独展示这些等待。

在固定时长 8 小时的隔离稳定性测试中完成至少 200 次工具操作、3 次插件/服务重启和一次 IM 重启；无未解决的数据丢失、重复外部效果、永久卡住运行或无法回收的停止状态。资源使用记录趋势和异常，不把机器无关的绝对内存数字当通用承诺。

UI 保持各版 320/390/900/1440px、200% 缩放/深浅色/键盘和错误状态回归；支持的平台和实际参考硬件由工程验收前锁定，不能测完后调整阈值以掩盖失败。

8 项必须通过，前三版回归通过，阻断缺陷为零，并有用户对指定构建的接受记录，才允许标记 released。发布动作仍按用户授权执行。
