# v1.0 验收清单

状态：全部 pending。依据 [PRD](prd.md)，对发布候选执行前三版完整回归。

## 环境与用例

锁定参考设备/支持平台、干净安装环境、20 人/50 群/50,000 消息/100 工作数据集、两类独立能力及故障注入。至少两种插件/服务版本用于兼容测试；所有敏感数据使用隔离夹具。

| 用例 | 需求 | 前置与步骤 | 通过标准与证据 |
| --- | --- | --- | --- |
| P10-A01 | P10-R01 | 在支持矩阵的干净环境安装/启动，配置模型；模拟依赖/端口失败 | 无相邻源码要求，错误可诊断，独立主流程可用；产物/环境与录屏 |
| P10-A02 | P10-R02 | 有活跃/未决操作时按流程备份，恢复 IM/能力并核对引用 | 历史/权限/版本一致，未决效果查询/对账，不重复；恢复报告 |
| P10-A03 | P10-R03 | 旧版数据升级，新 schema/契约误配，兼容与不可兼容回退 | 迁移可追溯，未知版本不误写，不兼容时执行已验证恢复；前后数据摘要 |
| P10-A04 | P10-R04 | 重跑身份/观察/多工作、资料/缓存/撤权与凭据负向场景 | 无越权正文/摘要/引用、无冒名调用，真实 API 拒绝且无副作用 |
| P10-A05 | P10-R05 | 8 小时内至少 200 操作，3 次插件/服务重启与 1 次 IM 重启，断网/取消 | 无未决数据丢失/重复效果/永久卡住；队列与停止可恢复，记录资源趋势 |
| P10-A06 | P10-R06 | 固定参考数据，预热后 30 次会话查询/切换；多宽度/缩放/主题回归 | 本地最近页/切换读取 p95 ≤ 1 秒；远程/模型单列；UI 主流程无遮挡 |
| P10-A07 | P10-R07 | 跟踪失败与成功调用、核对账本，并导出诊断；注入密钥/私聊 canary | 来源/用量可核对，恢复入口有效，导出不泄露敏感数据 |
| P10-A08 | P10-R08 | 核对 PRD/实施/用例/缺陷，用户体验指定候选，检查发布/恢复包 | 全部 must 有本次证据，阻断为零，用户结论真实，发布记录完整 |

## 结论

8/8 与前三版回归通过仅形成工程证据；必须有真实用户验收接受才能发布。记录至[验收模板](../../acceptance-record-template.md)实例，失败、blocked 或待测任一 must 项都阻断 release。
