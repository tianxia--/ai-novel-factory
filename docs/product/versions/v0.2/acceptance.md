## 环境与用例

不安装小说插件；准备资料检索与数据分析两类独立能力、一组含私有 canary 的文档、一份固定 CSV、一个第三方测试连接器、两人/两群/两工作。夹具与真实模型运行分别记录。

| 用例 | 需求 | 前置与步骤 | 通过标准与证据 |
| --- | --- | --- | --- |
| P02-A01 | P02-R01 | 安装兼容/不兼容插件，连接失败后重试，再停用/卸载 | 各状态真实，不兼容工具不可执行；历史保留；版本协商日志 |
| P02-A02 | P02-R02 | 给人物只挂 Skill、不授权工具；再授予工具但不给资料；最后补齐 | 前两次明确缺项，补齐后才执行；工具列表与网关拒绝证据 |
| P02-A03 | P02-R03 | 同一人工作 A 用临时工具/账号，工作 B 不选；完成 A 后再试 | B 无法借用，A 临时授权到期，无永久资格增长；绑定/epoch 证据 |
| P02-A04 | P02-R04 | 模型提交伪 actor/凭据/越界资源和旧 invocation 重放 | 身份由网关派生，越界拒绝，同键异参数冲突；提供方也拒绝无权资源 |
| P02-A05 | P02-R05 | 私聊读私有文档，在群中要求引用；切换资料版本和检索范围 | 原文/摘要/引用均遵守范围，未授予披露时群内无 canary；引用版本可核对 |
| P02-A06 | P02-R06 | 运行中撤销工具/知识，尝试后续读取与提交；恢复为新运行 | 旧许可不再使用，受影响执行收束/待核对，新 Session 不含已撤来源；事件证据 |
| P02-A07 | P02-R07 | 长操作受理后断线/重启/重试，取消与完成竞争，注入未知结果 | 原 operation 可查询，无重复效果，显示真实取消/完成/待核对，不盲目重做 |
| P02-A08 | P02-R08 | 重复投递同一完成事件，再产生新成果版本，分别向获准群交付 | 每个结果/版本/受众一次，作者和来源正确，普通最终文本不重复广播 |
| P02-A09 | P02-R09 | 完成文档检索引用与 CSV 统计报告，再安装第三个测试连接器 | 两类真实任务可核对；第三项经通用发现执行；IM 核心/表无业务特判改动 |
| P02-A10 | P02-R10 | 两工作交替执行并分别停用/卸载一个能力、停止一个服务 | 不串资料/账号/Session；普通 IM 和另一能力继续；恢复后查询原任务 |
