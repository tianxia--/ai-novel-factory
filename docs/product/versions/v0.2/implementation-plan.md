## 数据、升级与交付

IM 保存安装、授权、工作绑定、外部引用和调用/交付记录；提供方保存业务事实/operation/领域知识。每个工作有可追踪来源与配置快照。新增字段/表由所在项目迁移，不能要求三方代码在一个工作区构建。

停用/卸载保留历史引用；撤销运行许可不删除已发生效果。能力故障时可回到仅通信模式，但本版必需能力用例失败仍不通过。发布记录带平台、插件、服务和契约兼容范围。
