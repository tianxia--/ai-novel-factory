# v0.3 验收清单

状态：全部 pending。依据 [PRD](prd.md)，继承 P01/P02 验收基线。

## 环境与用例

三个人物、两个群、两类独立能力、多版本成果；可注入崩溃/租约丢失/乱序事件的隔离环境。真实模型协作与确定性恢复测试分别出具结果。

| 用例 | 需求 | 前置与步骤 | 通过标准与证据 |
| --- | --- | --- | --- |
| P03-A01 | P03-R01 | 三人讨论任务，分别接受/拒绝；协调人替他人承诺/超范围变更 | 只有本人有效接受，拒绝与变更可追踪，角色名不升权；承诺事件/录屏 |
| P03-A02 | P03-R02 | 闲聊、沉默、群 @、多轮讨论与私聊后接续，触达策略上限 | 无强制全员必答/自动建任务，收件/路由可解释且有界；真实与规则证据 |
| P03-A03 | P03-R03 | A 等 B、B 等 C、C 再等 A；另测拒绝、超时和迟到回复 | 循环不死锁，等待资源释放，来源与原工作不丢，未完成不标成功 |
| P03-A04 | P03-R04 | 两 worker 抢同人写任务，另一人并行；切工作与租约代际 | 单人不双写，旧代际提交拒绝，另一人正常；资料/负荷无越界 |
| P03-A05 | P03-R05 | 在受理、写入、交付窗口崩溃并恢复，停止后投递旧事件 | 查询原 operation，对账未知效果，消息/外部效果不重复，旧运行不复活 |
| P03-A06 | P03-R06 | 审阅成果 v1 后作者提交 v2；用旧 review 请求批准；并发正式提交 | 旧批准失效/拒绝，明确当前版本，提供方规则有效；资源版本/评审记录 |
| P03-A07 | P03-R07 | 从消息/工具建立记忆，更正/撤销来源，再观察人物并跨工作检索 | 来源可追溯，越界记忆不泄漏，撤回影响上下文，观察不写入 |
| P03-A08 | P03-R08 | 委派拆成多个子请求、错误后重试，耗尽/超时后再调用 | 同一总额度不被绕过，停止与原因真实，预留/消耗/释放与账单一致 |

## 结论

必须 8/8 通过并完成前两版回归。无法证明恢复/预算/授权正确时不得仅凭一次成功演示通过。具体构建和用户验收写入[验收记录](../../acceptance-record-template.md)。
