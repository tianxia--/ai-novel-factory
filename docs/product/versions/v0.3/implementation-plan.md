T01/T02 先定义事实和唤醒，T03 建立单写者/恢复；T04/T05 复用 v0.2 资源与授权，T06 对所有委派/调用生效。不能先让模型自由产生不可恢复外部动作后再补账本。

## 数据与回退

新增 IM 承诺、等待、租约、预算和记忆来源记录分别迁移；不把领域状态搬进 IM。投递、预算、效果和记忆分别有幂等标识及来源，日志关联到同一工作但不扩大正文可见性。

回退前停止新委派、收束写运行，保留所有未决操作/等待以便兼容版本核对。不通过重新提交整项工作来“恢复”。只读观察与已发布历史必须持续可用。

交付具体构建、状态迁移说明、故障窗口验证、真实协作记录和未决项。工程通过后由用户确认这个版本的协作体验。
