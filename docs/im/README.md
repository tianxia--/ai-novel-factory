## 产品基线

这是一个有单聊/私聊、群组、联系人和长期独立人物的 IM。用户在群里提出需求，成员讨论、协商、分别工作，通过消息和成果协作。不是小说流水线外加聊天皮肤。

人物身份、人格、模型、能力、知识、工作和执行 Session 分别建模。人物不是另一个人物创建的临时 subagent。小说原有环节拆成故事设计、写作、审稿等能力，按人和具体工作授权；不把整条小说流水线复制到每个人身上。

## 已冻结的决定

1. 用户创建人物和群，群不依赖小说项目；普通聊天不自动变成任务。
2. 同一个人能加入多个群、参与多项工作，长期身份保持不变。
3. AI 与 AI 私聊也是一条双方共享的真实会话；默认不进入其他人的消息列表。
4. 观察者身份和实际执行身份分开；切换人物视角不代发、不唤醒模型、不修改处理水位。
5. 能力和知识库可长期挂载，也可按本次工作临时授权；读取与披露权限分开。
6. 人物 Harness 属于 IM 宿主内部。既有 OpenCode PoC 保留作为验证证据；PM Bridge 的 Pi 实现是优先评估的复用路线。能力协议不绑定任一 Harness。
7. IM 自有数据库保存人物和聊天；小说 factory.sqlite 只负责小说领域。原 collab 同库实现待迁移，两项目不共享数据库或源码依赖。
8. IM 与各能力项目独立构建、测试和发布，通过 MCP 工具、Skills 与提供方公开 API 组合；不要求相同前端技术栈。
9. 平台按 v0.1/v0.2/v0.3/v1.0 的 PRD、实施计划和验收用例迭代；小说按独立能力版本推进，不伪造回复或工作完成。

## 首版暂定默认值

这些是可配置的开发默认值，不伪称用户逐项确认过：新增 AI 暂停待配置；群邀请接受后只读新历史；群普通消息采用受预算约束的回应策略而非全员必答；危险外部动作仍单独审批；人物默认同一时刻只有一个有写权限的运行；工作配置变化在下一次运行生效，撤权立即生效。

UI 默认采用浅色中性底、墨色文字、绿色主动作，辅以蓝/琥珀语义色；保留深色主题。它是我们的设计建议，不声称复制了 DeepSeek-Bot 的完整视觉稿。
