# UI 与交互规范

状态：实施规格，尚未接入正式界面。风格建议为“安静的工作型 IM”，采用熟悉的通讯软件结构，非任务看板、非营销首页。

## 1. 参考与差异

参考 DeepSeek-Bot 的长期人物、群聊、人物详情里的模型配置和能力库组织方式；它的公开说明也区分群上下文与私人会话。我们增加完整只读人物视角和按工作配置的能力/知识边界，不继承默认超级主管或以主 Bot 为中心的管理权限。[项目说明](https://github.com/Fei2411/DeepSeek-Bot)、[功能细节](https://github.com/Fei2411/DeepSeek-Bot/blob/main/ds-bot/README.md)

这是交互参考，不复制其品牌或未经核对的视觉样式。本轮没有获得可验证的完整当前界面截图，不宣称像素级复刻。

## 2. 布局

桌面：64px 导航栏 + 280px 会话/名录列表 + minmax(360px, 1fr) 内容区。详情面板展开宽 320px，空间不足时变为抽屉，不持续挤压正文。1280px 以下优先收起详情，900px 以下改为列表/会话两级导航；手机一次只显示一层，顶部明确返回，输入区避开软键盘和安全区。

导航主入口为消息、人物、群组；工作、能力、知识和设置为次级入口。没有人物时展示真正空状态和“创建人物”；有会话时恢复上次有权访问的会话，不先显示欢迎营销页。

顶部人物选择器常驻“我的视角”。选择人物进入只读观察，标题、头像和状态同时变化；观察者身份不随切换而变化。返回我的视角恢复自己的草稿、会话和滚动位置。

## 3. 视觉参数

| 项目 | 默认规范 |
| --- | --- |
| 浅色背景 | 内容 #FFFFFF，列表 #F5F6F8，分隔线 #E3E6EA |
| 文字 | 主文字 #202329，次文字 #666D78，禁用 #9299A3 |
| 动作/状态 | 主动作 #18794E，链接 #2563B8，注意 #9A6700，危险 #C63737 |
| 深色主题 | 中性炭黑底 #181A1E / #21242A，文字 #ECEFF3；不是深蓝主题 |
| 字号 | 正文 14px，消息 15px，标题 18px，辅助 12px；字距 0 |
| 间距 | 4/8/12/16/24px；按钮高度 32/36px，触摸目标至少 44px |
| 圆角 | 面板/重复项不超过 8px；头像圆形；无嵌套卡片 |
| 图标 | Lucide 本地资产，工具按钮有 tooltip 和 aria-label |
| 媒体 | 人物真实上传头像或明确的人物插画；资源预览展示实际内容 |
| 动效 | 120–180ms，尊重 reduced-motion；无假打字与装饰性光球 |

列表是可扫描的行，分区用分隔线，不把每页套成浮动卡片。消息正文可选中、复制、换行；长链接和文件名断行。所有控件保持稳定尺寸，不因 hover、状态或长姓名挤动布局。

| 工作详情 | 请求/承诺、执行人、本次配置、进度、成果 | 不是聊天前置；等待、受阻、停止中、待核对明确 |
| 能力库 | 技能、工具/MCP、能力包、版本和安装来源 | 安装与授权分开，危险命令审批，禁用保留历史 |
| 知识库 | 库/文档、来源、版本、索引进度、授权 | 上传/索引失败可重试，原文/摘要同权限 |
| 成果 | 指定版本、正文/预览、引用、审阅与差异 | 无权版本不可见，旧评审不算新版本通过 |

## 5. 关键操作细节

### 消息编辑与发送

发送是明确命令，附件、引用、能力配置使用图标按钮。Enter 发送，Shift+Enter 换行，输入法 composition 期间 Enter 不发送。键盘提示放 tooltip/帮助，不占据正文。输入区保存按“实际作者 + 会话 + 工作”隔离的草稿。

发送后先显示本地待发送项，收到服务端 ID 后替换；网络超时使用同一 clientRequestId 重试，不凭超时判断服务端未提交。失败项保留正文并可重试/编辑。服务端拒绝权限时不能仍留下假成功消息。

群里可显示工具交付结果，但原始 token 流和私人推理不自动广播。显式 sendMessage 与最终 assistant 文本不能各发一次。工具执行事件、工作进展、公开消息是不同对象。

### 人物视角

切换立即取消或标记上一视角请求失效，响应缓存键包含 workspace、viewer、subject、权限 epoch。迟到响应不覆盖当前页面。只读观察隐藏发送和上传入口；后端同样拒绝所有写命令，不能只依赖禁用按钮。

### 本次能力与知识

工作抽屉按执行人显示“继承项 / 本次临时项 / 不可用项”，可选知识库到文档与版本，显示工具账号的脱敏别名和到期条件。作用域切换用分段控件，二元授权用复选框，数值预算用输入/步进器，不用一排文字胶囊替代工具图标。

保存前显示权限变化；默认下次运行生效。撤销立即生效并说明受影响工作，显示取消/对账过程，不假装瞬间删除了模型已收到的信息。普通聊天可不打开此面板。

### 邀请、离群和归档

邀请与接受分开显示。新成员没有旧消息时不是加载失败；可明确共享简报。离群前说明收不到后续消息；重入产生新历史起点。群归档不删除人物或 DM；删除资料须说明依赖的引用/索引/备份处理。

## 6. 状态文案与可访问性

运行状态只使用真实事实：待配置、暂停、待处理、执行中、等待回复、停止中、已停止、失败、待核对。头像装饰不能伪造 presence。每页有空、忙、错、权限不足和离线态；错误给出可以执行的下一步，不展示堆栈/密钥。

所有功能有键盘路径和可见 focus；对话框捕获并恢复焦点，Esc 关闭非破坏性面板；图标有可读名称，错误与进度使用适当 live region。语义状态同时有文字，不仅靠颜色。

## 7. UI 验收

至少覆盖 1440/1280/900/390/320px、200% 缩放、深浅色、长姓名、超长单词、消息很多、空数据、中文输入法、慢网络、重试、视角竞态与权限撤销。检查截图和实际交互，未实现功能不显示为可点击成功状态。正式 UI 接入后再给可访问地址和截图，本规格不是可运行原型。
