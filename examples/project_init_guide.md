# 项目初始化和设定完成指南

> 本指南帮助你正确初始化项目并完成所有必要的设定，然后才能开始写作

---

## 🎯 初始化流程

### 第一步：检查项目状态

```bash
# 在 OpenCode 中执行
使用 opencode-ai-novel-factory 的 novel-status 工具
```

**查看：**
- ✅ 设定文件是否创建
- ✅ 设定文件是否完成
- ✅ Vocabulary 是否安装
- ✅ 写作风格指南是否创建

---

### 第二步：完成世界观设定

```bash
# 在 OpenCode 中执行
请帮我创建世界观设定
```

**AI 会引导你填写：**
1. 世界背景（古代、现代、玄幻等）
2. 世界规则（法术等级、社会制度等）
3. 主要势力（国家、门派、家族等）
4. 地理环境（大陆、海洋、城市等）
5. 历史背景（重要历史事件）

**填写要求：**
- 至少 100 字
- 至少 20 行
- 内容要具体、清晰

**示例世界观设定：**
```
这是一个以古代中国为背景的玄幻世界。

世界规则：
- 修炼分为炼气、筑基、金丹、元婴、化神五个境界
- 每个境界分为初期、中期、后期
- 炼气期可习得基础法术，筑基期可飞行

主要势力：
- 朝廷：统治凡人界
- 宗门：分正魔两派，正派有青云门、天剑宗等
- 家族：李家、王家、赵家等世家大族

地理环境：
- 东大陆：以修仙为主
- 西大陆：以凡人为主
- 中州：朝廷所在地

历史背景：
- 五百年前，魔族入侵，修仙界大乱
- 三百年前，正魔大战，魔族退回西域
- 一百年前，天剑宗崛起，成为正道领袖
```

---

### 第三步：完成故事大纲

```bash
# 在 OpenCode 中执行
请帮我创建故事大纲
```

**AI 会引导你填写：**
1. 故事主线（核心冲突）
2. 主要转折点（3-5个）
3. 分卷规划（每卷10-50章）
4. 结局设定（结局类型）
5. 主题思想（核心主题）

**填写要求：**
- 至少 100 字
- 至少 20 行
- 结构清晰，逻辑连贯

**示例故事大纲：**
```
故事主线：
少年李云在家族废墟中发现神秘玉佩，踏上修仙之路，
寻找父母失踪的真相。

主要转折点：
1. 李云拜入青云门，被测出火灵根
2. 发现玉佩是上古法宝，与父母失踪有关
3. 魔教袭击青云门，抢夺玉佩
4. 李云逃出青云门，被天剑宗收留
5. 得知父母是天剑宗叛徒，为保护玉佩牺牲

分卷规划：
第一卷：青云门（第1-10章）
- 李云加入青云门，学习基础法术
- 发现玉佩秘密

第二卷：天剑宗（第11-20章）
- 魔教袭击，李云逃亡
- 拜入天剑宗，真相浮出

第三卷：真相大白（第21-30章）
- 调查父母过去
- 与魔教决战

结局设定：
- 开放式结局（为续集留伏笔）

主题思想：
- 成长、友情、亲情、责任
```

### 第四步：完成主角设定

```bash
# 在 OpenCode 中执行
请帮我创建主角设定
```

**AI 会引导你填写：**
1. 基本信息（姓名、年龄、性别、身份）
2. 外貌特征（身高、体形、面容）
3. 性格特点（优点、缺点、爱好）
4. 背景故事（出生、成长、经历）
5. 能力设定（天赋、技能、装备）
6. 成长轨迹（起点→终点）

**填写要求：**
- 至少 100 字
- 至少 20 行
- 人物立体，有血有肉

**示例主角设定：**
```
基本信息：
- 姓名：李云
- 年龄：16岁
- 性别：男
- 身份：青云门外门弟子

外貌特征：
- 身高：175cm
- 体形：偏瘦，但有肌肉
- 面容：清秀，眼神坚毅
- 特征：眉心有一道浅浅的疤痕

性格特点：
- 优点：坚韧、正义、重情义
- 缺点：冲动、容易轻信
- 爱好：修炼、看书、游山玩水

背景故事：
- 出生：东海小村庄
- 成长：5岁时父母失踪，被村民抚养
- 经历：12岁发现修仙天赋，15岁拜入青云门

能力设定：
- 天赋：火灵根（上品）
- 技能：基础剑法、火球术、轻身术
- 装备：青钢剑、储物戒

成长轨迹：
- 起点：16岁，炼气初期
- 第一卷终点：18岁，炼气后期
- 第二卷终点：20岁，筑基初期
- 第三卷终点：22岁，金丹初期
```

```bash
写第1章，请按照以下要求执行：

1. 严格按照 studio/style/writing_style_guide.md 的风格指南
2. 当前场景：[描述场景，如青云门招收弟子]

4. 根据场景选择合适的文言文比例（20%）
5. 根据角色身份选择成语使用策略（低）
6. 确保成语与上下文有明确关联
```

## 💡 重要提示

### 为什么必须完成设定？

1. **世界观是故事的基础**
   - 没有世界观，AI 不知道故事发生在哪里
   - 没有规则，AI 不知道什么能做什么不能做

2. **大纲是故事的骨架**
   - 没有大纲，AI 不知道故事走向
   - 没有转折点，故事会平淡无奇

3. **主角是故事的灵魂**
   - 没有角色设定，AI 不知道主角的性格
   - 没有成长轨迹，主角会一成不变

### 设定完成的标志

**世界观设定：**
- 至少 100 字
- 至少 20 行
- 包含：世界背景、规则、势力、地理、历史

**故事大纲：**
- 至少 100 字
- 至少 20 行
- 包含：主线、转折点、分卷、结局、主题

**主角设定：**
- 至少 100 字
- 至少 20 行
- 包含：基本信息、外貌、性格、背景、能力、成长

## 🔧 故障排除

### 问题1：novel-status 显示设定未完成

**解决方案：**
```bash
# 1. 查看具体是哪个文件未完成
使用 opencode-ai-novel-factory 的 novel-status 工具

# 2. 补充未完成的文件
请帮我完善世界观设定 / 故事大纲 / 主角设定
```

### 问题2：AI 还是跳过设定直接写作

**解决方案：**
```
请先完成以下设定，然后再开始写作：

1. 请帮我完善世界观设定，至少100字
2. 请帮我完善故事大纲，至少100字
3. 请帮我完善主角设定，至少100字

完成后，请告诉我"设定已完成"
```

### 问题3：写作时提示设定未完成

**解决方案：**
```
请先完成设定，然后再开始写作：

1. 查看设定文件状态
2. 补充未完成的设定
3. 完成后再尝试写作
```

## 🎯 关键要点

1. **必须先完成设定** - 不能跳过
2. **设定要足够详细** - 至少100字、20行
3. **设定要清晰合理** - 逻辑连贯
4. **完成后检查** - 用 novel-status 确认
5. **确认后再写作** - 确保所有设定都已完成

---

**记住：没有好的设定，就不会有好的小说。花时间完善设定，是值得的！**
