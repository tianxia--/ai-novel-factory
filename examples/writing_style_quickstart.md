# 写作风格指南 - 快速开始

> 本指南帮助你让 AI 知道如何按照正确的风格写小说

---

## 🎯 核心理念

AI 在每次写作前，会自动读取 `studio/style/writing_style_guide.md`，并严格按照指南执行。

**写作风格指南包含：**
1. 📖 写作风格总原则
2. 🎯 成语使用策略（与角色、场景关联）
3. 📖 文言文穿插策略（比例、场景、词汇）
4. 🎭 角色差异化写作（身份、性格、场合）
5. 📝 写作流程（写作前、中、后）
6. 🎯 写作模板（对话、叙述、文书）
7. 💡 快速参考

---

## 📖 写作风格指南速查

### 成语使用密度

| 场合 | 成语密度 | 每段 | 每章 |
|------|---------|------|------|
| 正式奏章 | 高 | 2-3个 | 10-15个 |
| 正式对话 | 中 | 1-2个 | 5-8个 |
| 随意对话 | 低 | 0-1个 | 2-4个 |
| 战场指挥 | 低 | 1个 | 3-5个 |
| 私下交谈 | 低 | 0-1个 | 2-3个 |

### 文言文使用比例

| 文本类型 | 现代文 | 文言 | 适用场景 |
|---------|-------|------|---------|
| 普通叙述 | 80% | 20% | 日常叙述 |
| 对话（非正式）| 95% | 5% | 朋友聊天 |
| 对话（正式）| 60% | 40% | 官员交流 |
| 奏章文书 | 20% | 80% | 正式文书 |
| 古书信 | 30% | 70% | 文人书信 |
| 史书叙述 | 40% | 60% | 史书记载 |

### 角色差异

**文人/官员：**
- 文言：30-40%
- 成语：中等到高
- 风格：文雅、含蓄

**武将/粗人：**
- 文言：5-10%
- 成语：低
- 风格：直白、有力

**平民/百姓：**
- 文言：0-5%
- 成语：几乎不用
- 风格：日常、朴素

## 💡 实践技巧

### 技巧1：写作前分析

**在 OpenCode 中让 AI 这样说：**
```
写作前，请先分析：
1. 当前是什么场景？（战场、朝堂、日常等）
2. 主要角色是什么身份？（文人、武将、平民等）
3. 主要角色什么性格？（谦虚、张扬、憨厚等）
4. 应该用什么文言文比例？
5. 应该用什么成语密度？
```

### 技巧2：分段写作

**在 OpenCode 中让 AI 这样说：**
```
请分3步写第X章：

步骤1：先用基础词汇写出内容，确保表达完整
步骤2：根据角色和场景调整词汇，适当使用文言文
步骤3：在关键处（总结、强调、对比）使用成语

每步完成后，请告诉我进入下一步
```

### 技巧3：风格检查

**在 OpenCode 中让 AI 这样说：**
```
写完第X章后，请按照 studio/style/writing_style_guide.md 的检查清单自检：

检查项：
- [ ] 成语是否符合角色身份？
- [ ] 成语是否符合性格特征？
- [ ] 成语是否符合场合氛围？
- [ ] 成语是否与前文有关联？
- [ ] 成语密度是否合理？
- [ ] 文言文比例是否合适？
- [ ] 文言词汇是否正确？
- [ ] 风格是否统一？
- [ ] 是否保持可读性？

请逐一检查，并告诉我结果
```

## 🔧 故障排除

### 问题1：AI 还是成语泛滥

**解决方案：**
```
请严格按照 studio/style/writing_style_guide.md 中的成语使用密度表执行：

当前场景：随意对话
成语密度：低（每段0-1个，每章2-4个）

请确保：
1. 成语有前文铺垫
2. 成语与上下文有明确关联
3. 不要堆砌成语
```

### 问题2：文言文比例不对

**解决方案：**
```
请严格按照 studio/style/writing_style_guide.md 中的文言文使用比例表执行：

当前场景：日常叙述
文言文比例：20%
现代文比例：80%

请确保：
1. 使用少量文言词汇（如：吾、汝、闻）
2. 保持现代文为主
3. 不要为了用文言而用文言
```

### 问题3：角色风格不统一

**解决方案：**
```
请严格按照 studio/style/writing_style_guide.md 中的角色差异化执行：

角色：李大人（文臣）
风格要求：
- 文言文比例：30-40%
- 成语密度：中等到高
- 词汇风格：文雅、含蓄
- 表达方式：委婉有礼

请确保全文保持一致
```
